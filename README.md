# Eduleb Demo Site

This repository is the production-style Eduleb implementation.

## Editable page map

- `index.html` -> `src/pages/Home01.tsx`
- `index2.html` -> `src/pages/Home02.tsx`
- `about.html` -> `src/pages/AboutPage.tsx`
- `course.html` -> `src/pages/CoursePage.tsx`
- `course_details.html` -> `src/pages/CoursePage.tsx` (`CourseDetailsPage`)
- `instructor.html` -> `src/pages/InstructorPage.tsx`
- `instructor_details.html` -> `src/pages/InstructorPage.tsx` (`InstructorDetailsPage`)
- `pricing_plan.html` -> `src/pages/PricingPage.tsx`
- `faq.html` -> `src/pages/FAQPage.tsx`
- `blog.html` -> `src/pages/BlogPage.tsx`
- `blog_details.html` -> `src/pages/BlogPage.tsx` (`BlogDetailsPage`)
- `contact.html` -> `src/pages/ContactPage.tsx`
- `404.html` -> `src/pages/ErrorPage.tsx`

Mock content lives in `src/data/edulebMock.ts` and is intentionally easy to replace with live records later.
